Decent sized attrition map with custom bounce pads that launch players into the sky. Balancing is yet to be properly tested.

Required on both client and server side in order to work. Will crash unless impact marks are disabled in settings, but there is a script that automatically disables them. There is a known bug that causes some brushes in the distance to disappear from certain angles, but the bug is purely visual and does not effect gameplay.

To access the map, enter the private match menu and type this:
map mp_bounce_city
